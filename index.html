尚未初始化

此页面需要先生成加密库，并把数据与页面推送到 GitHub 仓库。

  1. 在电脑上运行 node scripts/init_vault.mjs，设定至少 12 字符的口令。
  2. 运行 node scripts/sync_weread.mjs --push，同步微信读书数据。
  3. 提交 vault.meta.json 与数据文件，在仓库设置中开启 GitHub Pages。

口令由使用者自行设定，不写入任何文件。完整步骤见仓库 README.md。请通过 http(s) 地址打开本页面，不要直接双击本地文件。

读书笔记工作台

内容以密文保存在公开仓库，口令仅用于在本机解密，不会上传。

安全边界

本工作台保护的是内容机密性，不是访问权限。页面与仓库公开，任何人都能下载密文、看到文件名与提交时间；没有口令则读不到内容，也解不开写回令牌。

解锁是本地行为，没有服务端账号或会话。忘记口令无法恢复，请自行保管并定期导出备份。

未配置写回令牌时自动进入只读模式，适合手机查看。
